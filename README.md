# Dash SNES v1.0

**Super Nintendo emulator for Windows 10/11 (64-bit)**

Dash SNES is an independent Super Nintendo emulator focused on simplicity, preservation, customization, and a clean desktop experience.

Open the emulator, point it to your ROM collection, scan your library, and start playing.

## ✨ Features

* 📚 **Automatic Game Library**

  * Scan a ROM folder automatically
  * Game covers and genres
  * Organized collection management

* 🎮 **Custom Controls**

  * Keyboard support
  * Gamepad support
  * Fully configurable button mapping

* 💾 **Save & Rewind**

  * Game saves
  * Rewind gameplay
  * Turbo functionality

* 🖥️ **Video Options**

  * Pixel-perfect rendering
  * CRT-style presentation
  * Flexible scaling and display sizes

* 🔊 **Audio**

  * Integrated SNES audio emulation
  * Stable and continuous playback

* 🧩 **Cheat System**

  * Enable and disable cheat codes
  * Create custom codes directly from the emulator

* 🛠️ **Developer Mode**

  * Real-time memory inspection
  * Graphics/debug information
  * Tools intended for development and experimentation

* 🎨 **Themes**

  * Customizable colors
  * Interface density
  * Font customization

* 🌎 **8 Languages**

  * English
  * Portuguese (Brazil)
  * Spanish
  * French
  * Russian
  * Japanese
  * Korean
  * Chinese

## 🔒 Privacy

Dash SNES is designed to keep your local game collection on your computer.

Nothing is sent anywhere unless you explicitly request it. Cover artwork can come from the built-in artwork pack or your own folders, while API keys remain stored in your local user profile.

## ⚙️ Technical

Dash SNES is distributed for:

* Windows 10
* Windows 11
* 64-bit systems

The emulator incorporates open-source components including the **bsnes core**, **SPC DSP**, **libco**, and **LZMA SDK**, with their respective licenses and credits included with the application.

## 📦 Included

This release contains the Windows 64-bit build of Dash SNES.

No ROMs or copyrighted game files are distributed with the emulator.
